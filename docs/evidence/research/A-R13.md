- **A-R13｜全域暫停、單一任務暫停與人工強制執行，有哪些邊界？** 官方明確指出：暫停排程不等於終止正在執行的工作，也不是阻止人工執行的安全邊界。([hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron))
- **全域暫停：**`hermes pause` 阻止自動排程啟動，涵蓋內建 ticker、託管排程 webhook 與漏跑補償；已在執行的工作不會被殺掉。人工 `hermes cron run` 或介面 Trigger 仍可覆蓋暫停而執行。([hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron))
- **單一任務暫停：**`cron pause` 保留任務、停止自動排程。既有週期任務暫停期間到期，恢復後會在下一 tick 補跑一次；若 `cron.catch_up_missed: false`，則記錄跳過。以 `--paused` 新建的任務則在恢復時排定下一個未來時點。([hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron))
- **人工執行的限制：**官方說明明確允許 Run now／force-run 覆蓋暫停，部分流程也可能恢復任務。**推論：**不能只靠 paused 狀態實施需要禁止人工啟動的 Safety STOP；操作權限與授權控制必須另外成立。([hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron))
